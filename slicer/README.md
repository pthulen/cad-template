# Slicer projects

Commit Bambu Studio project files (`.3mf`) here: print settings are part of the product.

A project file records the filament, layer height, walls, infill, supports and
plate layout that produced a good print. Without it, "the same STL" can print
very differently a year from now.

Suggested naming: `<variant>-<material>.3mf`, for example `small-pla.3mf`.
When you change settings after a test print, re-save the project and log the
change in `notes/TESTLOG.md`.
